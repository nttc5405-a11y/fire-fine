# 消防執法開單速查

提供臺東消防執法人員查找限期改善、逕行舉發與舉發並限改的作業參考。內含 53 項情境、單據欄位草稿、四種表格式樣板及原始資料連結。

## 使用

以瀏覽器開啟 `index.html`，或以靜態網站服務執行。沒有套件安裝或建置步驟。雲端附件仍須具備原檔的存取權限。

手機提供底部導覽、情境詳情切換、填寫／預覽分頁，以及整張單據預覽、原尺寸放大與完整 PNG 圖片下載。手機可用瀏覽器雙指縮放，儲存圖片後亦可離線放大對照手寫。列印維持 A4 表格。

## 資料與維護

- `data.js`：情境、構成要件提示、法條與來源。
- `gas-cases.js`、`gas-ui.js`、`gas.css`：液化石油氣原編號 1～10 類案件、現場步驟、蒐證及談話查證；含 0 號總覽、非法灌裝簡報與共同談話紀錄的整理。
- `firework-cases.js`、`firework-ui.js`：爆竹煙火 32 類情境、細分類、共同表單與原檔核對差異。
- `catalog.js`：雲端附件索引與查閱狀態。
- `app.js`：搜尋、條件分流、文字草稿及作業檢核。
- `forms.js`、`forms.css`：單據欄位與 A4 版型。
- `mobile.js`、`mobile.css`：手機導覽與工作區。
- `download.js`、`sheet-view.css`：整張單據檢視及高清 PNG 下載。
- `reference-limit.png`：原始空白限改單版面，供比對。

案件欄位僅在當頁記憶體處理，不寫入瀏覽器儲存空間、不上傳、不代送；重新整理後清除。剪貼簿、下載及列印檔案由使用人員保管。

## 使用範圍

本網站是參考模板，並非機關核定表單或裁處系統。單據格線依原表重建，沒有印信、職名章或親簽。法規構成要件、義務人、改善期限、送達及救濟告知，仍須依個案與最新版正式規定確認。

資料查閱日期為 2026 年 11 月 20 日；部分附件僅列出目錄，詳細差異及查閱限制見網站的「來源與版本」。
